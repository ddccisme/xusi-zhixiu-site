## 6. 标准操作流程

### 6.1 重建数据

```bash
cd /Users/andy_dongcheng/Desktop/DC_WORK/WORKSPACE/16_文娱产业项目/00_web
source .venv/bin/activate
python scripts/build_kb.py          # 增量构建数据库
python scripts/build_vectors.py     # 重建向量索引
python scripts/search_server.py     # 启动搜索服务
```

### 6.2 生成 AI 评鉴

```bash
# 测试（本地 Ollama，质量一般）
python scripts/ai_appreciation.py --limit 20

# 正式（Kimi API，推荐）
export KIMI_API_KEY=your_key
python scripts/ai_appreciation.py --provider kimi --model moonshot-v1-8k --limit 100
```

### 6.3 内容编辑原则

- `kb/` 是内容唯一来源
- 所有内容修改应在 Obsidian 中完成
- 不要直接修改 SQLite 数据库
- 修改后运行 `build_kb.py` 同步
