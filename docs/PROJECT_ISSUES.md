## 文档说明

本文档用于跟踪项目中的已知问题、技术债务、风险与阻塞项。问题按严重程度分为：

- **🔴 严重**：影响核心功能或上线
- **🟡 中等**：影响体验或效率，有临时方案
- **🟢 轻微**：优化项，可后续处理

### ISSUE-002 以图搜图基于 pHash，非语义相似

| 属性 | 内容 |
|-----|------|
| 严重程度 | 🟡 中等 |
| 类型 | 算法局限 |
| 影响 | 上传图片搜索时，返回结果偏向构图/颜色相似，而非纹样语义相似 |

| 解决方案 | 接入 CLIP 或多模态模型，升级为语义相似 |
| 负责人 | 开发 |
| 状态 | 已规划，远期执行 |
| 计划完成时间 | 第三阶段 |
