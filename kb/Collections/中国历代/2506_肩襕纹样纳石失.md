# 肩襕纹样纳石失

## 描述

数量　  1件

尺寸(厘米)　　长：41 宽：33

形状内容描述　　纳石失是元代最著名、最有特点的加金织物，是波斯语织金锦Nasich的音译词。元代是中国历史上大量使用织金织物的时期，统治阶级"无不以金彩相尚"。官方大量织造纳石失，做衣服和日常生活中的帷幕、椅垫、炕垫。纳石失是特结型的加金织物，使用两组经线，一组专门起地组织，与地纬交织，另一组专门固结纹纬。肩襕图案是元代袍料上经常出现的，它们大都带有阿拉伯文字风格的图案，以圆圈和线条组成，纹样规整变形，上下左右，处处对称，高度程式化，与中国传统风格迥异，但和伊斯兰装饰十分接近。

## 艺术评鉴

此肩襕纹样纳石失，以四十一厘米之长、三十三厘米之宽，承载了一段蒙元帝国跨文明对话的织金记忆。其特结型双经结构，一组经线静默铺陈地组织，另一组则专司固结纹纬，经纬之间暗合分工之智，使金线得以安稳栖居于织物表层，既免磨损之虞，又获浮光跃金之效——此非单纯技术之巧，实为游牧贵族"以金彩相尚"的审美意志在机杼间的物化。

肩襕之制，本为袍服肩部横向装饰带，此件纹样以圆圈与线条组构，上下左右严整对称，高度程式化，与中国传统织绣之折枝花卉、云气走兽的流动气韵迥然有别。其阿拉伯文字风格之变形处理，不取可识读之语义，而采书法之笔势化为纯然装饰，此乃伊斯兰艺术"以纹代象"原则的典型呈现。蒙元统治者将波斯匠师迁入弘州、荨麻林诸局，纳石失遂成为宫廷与西域神职人员身份标识的双重载体——金线之耀目，既显财富之丰盈，亦暗合天光之神圣。

此件藏品最堪玩味处，在于其文化身份的暧昧性：它产自中原官营作坊，纹样却近伊斯兰装饰传统；它为蒙古贵族服用，却经由波斯语音译命名。这种多重叠合，恰是13世纪欧亚大陆物质流通的微观证词。金线历经数百年，或已黯淡，然其编织的文明经纬，至今仍在丝缕间微微震颤。
