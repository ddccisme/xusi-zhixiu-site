# 唐黄地团窠尖瓣对鸟纹锦

## 描述

时代　　唐朝

数量　  3 件

质地　  丝

色泽　　黄

形状内容描述　　同类图案的纬锦有三块。织物组织为1:1深蓝、黄二色右斜纹纬锦。织锦以三角形尖瓣团窠环为主花，团窠以细密的联珠纹圈外加尖瓣花边构成，窠中纹样为相对立于叶台之上的对鸟，窠外为十瓣花。此锦图案风格与收藏于瑞士Sens的一件黄地大窠尖瓣对狮赞丹尼奇锦十分相似，具有浓厚的中亚织锦风格。

## 艺术评鉴

此锦以黄地为天穹，深蓝纬线斜织，如夜气沉落于晨光之上，形成1:1右斜纹的微妙肌理——非经锦之挺括，而具纬线循环的柔韧与缜密，恰是唐代纬线显花技术西渐东融的物证。团窠取三角形尖瓣之形，联珠为骨、尖瓣为缘，窠环如西域穹庐之顶，又似莲花初绽之态，此乃萨珊波斯艺术语言入唐后的转译：联珠本为中亚草原的珠饰传统，尖瓣则近祆教艺术中的光焰象征，至长安匠人之手，竟化为温润的东方花腔。

窠中对鸟立于叶台，非汉魏之瑞鸟祥集，亦非南朝之逸态翩跹，而是相对伫立、凝止如仪，具一种仪式性的庄严。鸟身简括而神完，十瓣花散于窠外，如星斗环拱。与Sens所藏对狮赞丹尼奇锦遥相呼应，可知此类织锦乃跨文明订单的产物——或许出自粟特织工之手，或许为唐人摹写西域样稿，经纬之间，皆是丝绸之路双向流动的密码。

黄地之选尤可玩味。中原尚黄，隋唐以降更列之正色；中亚亦重金黄如日光。此色非妥协，而是共识，是帝国气象与游牧审美在物质层面的叠合。三块残锦存世，犹见当年整幅之辉煌，其审美价值不在完整，而在裂隙中透出的文明互鉴之光——盛唐之所以盛，正因其能以丝为纸、以梭为笔，书写一种不设边界的华丽。
