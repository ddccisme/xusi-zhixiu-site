# 元代墨绿回纹地雁衔花枝纹绫

## 描述

时代　　元代

数量　  3 件

质地　  丝

色泽　　墨绿

形状内容描述　　类似图案的织物有三块。织物组织为3枚正反斜纹绫。此花绫以墨绿色曲折的回纹为地纹，其上铺嘴衔花枝、双翅展开的飞雁。这种"锦地开光"的纹样格局在宋元之际十分流行。

## 艺术评鉴

墨绿回纹地雁衔花枝纹绫，以三枚正反斜纹之组织，织就元代丝织的一脉深沉。回纹屈曲如迷宫，墨绿为底，非张扬之色，乃幽微之致——那是北方草原入主中原后，尚青尚黑的审美余绪，亦是宋人雅意与元人阔略的折衷。飞雁衔枝，双翅展张，于几何骨架中破空而来，恰成"锦地开光"之格局：地纹的秩序与主纹的生动，一静一动，一隐一显，织工以经纬为笔墨，在方寸间经营出呼吸的间隙。

雁之为象，自古牵系南北迁徙、鸿帛传书之思；花枝则承宋人折枝之遗韵，纤秾合度。二者并置，非简单的祥瑞堆砌，而将流动的时间性——秋去春来、关山迢递——织入静止的丝缕。元代绫绮，多见于墓藏而罕存世用，此三幅墨绿之存，恰可见彼时织物如何从宋代的内敛秀雅，渐转向装饰密度的增加，却未失分寸。回纹的无限循环与雁的定向飞行，构成一组微妙的张力：一方是宿命的羁縻，一方是自由的渴念，终在墨绿的沉郁中达成和解。此种织品，非仅服用之物，乃元人宇宙观的一帧缩微。
