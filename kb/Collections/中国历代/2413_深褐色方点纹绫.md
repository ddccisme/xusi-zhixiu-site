# 深褐色方点纹绫

## 描述

时代　　辽

数量　  1片

质地　  丝

色泽　　深褐色

尺寸(厘米)　　长：  30.5  宽：27

形状内容描述　　该残片为一深褐色方点纹绫。绫，即一种斜纹地的暗花织物。方点纹，属于小几何纹，这类纹样在战国时期就已出现。

## 艺术评鉴

此绫残片虽仅存尺幅，却犹见辽地风烟。深褐之色，非浓艳夺目之态，乃经时岁浸染后的沉潜，如朔漠黄昏，如老木年轮，藏着北方民族对大地本色的亲近。斜纹为地，暗花隐现，正是绫之特韵——不彰不显，却于光影流转间自现肌理，此中原有中国织造的含蓄哲学。

方点纹者，小几何之遗绪也。溯至战国，此纹已见于楚地丝帛，历秦汉魏晋，至辽而犹存其脉。然辽人之用，非简单因袭：点阵方格，秩序俨然，既承中原织纹之矩矱，又暗合契丹鞍马民族对毡帐图案、铠甲编缀的视觉记忆。一纹之微，竟成南北互鉴的丝上证据。

尤可留意者，绫之工艺在辽代的存续本身。契丹崛起漠北，立国后设官营作坊，兼采唐宋制度，丝织遂为显业。此残片斜纹地的规整度，足见机杼未废；而暗花之素雅，又与辽代金银器的繁缛华丽形成对照——或许绫素本为常服之材，或作袍里、或充囊橐，乃日常之用，非庙堂之饰。正是这"用"的质地，使其逃过豪奢易朽之劫，以残片之躯，托住一段平实的物质生活史。

三十厘米见方的遗痕，边缘已见岁月啃啮，经纬间却仍有韧力。方点排列，如棋枰未竟之局，如星图散佚之页，引人悬想：何人曾衣此？曾行于上京之街，抑或随驼队没入草原深处？织物无言，唯以纹样与质地，将个体湮没的记忆，织入文明长卷的暗纹之中。
