# Maria Carmen Perez Pastor：山花（Tree Dress）

## 描述

作品是将欧根纱与植物丝以波吉技法缝纫而来。整个作品还原了一棵杏仁树，树上盛开的花是用丝绸手工绘成，并使用热球做成的立体形状。

Maria Carmen Perez Pastor是一名来自西班牙的手工艺人、时装设计师和纺织品创造者，同时也是“Carmen Pastor”品牌创始人。

她从事设计已经有30余年，不仅学习了时装、设计和服装，同时还学习了不同的丝绸绘画技巧、用羊毛制作丝毡、用天然染料染头饰和羽毛的等与时尚有关的技艺。这些设计和系列创造都在不同的t台上进行过展示。

## 艺术评鉴

此件《山花》以欧根纱为骨、植物丝为脉，借波吉技法之精微，织就一株异邦杏仁树。波吉技法源自法式传统，以细密针脚堆叠出浮雕般的肌理，作者却以此驯服欧根纱的轻飏与植物丝的柔韧，使二维平面生出三维的呼吸——热球塑就的花朵鼓胀如含露将绽，丝绸手绘的色泽自瓣尖向蕊心渐次消融，似晨光穿透薄雾时的层次。杏仁树在地中海文明中本是早春信使，此间却被转译为可穿戴的山林，衣裾曳动则花枝乱颤，人与自然的边界在针脚起落处悄然溶解。

最堪玩味的是其"树形裙裾"的意象：西方高定传统中，女性身体常被剪裁为花瓶或沙漏，此作则反其道而行，以躯干为干、裙摆为冠，将着装者纳入植物的生命节律。欧根纱的半透明性更添一层东方氤氲，使花影人影交叠互渗，恍若宋人折枝花鸟册页中走出的幽灵。迪金森诗云"群山昂首，河流俯身"，而人反不如自然有好奇之目——此作恰以衣为媒，令着装者复归草木的凝视，在丝纤毫末间重建一种前现代的灵性感知。三十年技艺的沉淀，终化作一树不结果的繁花，开在西丝博的展柜中，亦开在时装与纤维艺术的裂隙之间。
