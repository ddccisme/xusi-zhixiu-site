# Set／套装

## 描述

Date / 时期：1960s

Designer / 设计师: Roberta di Camerino（1920-2002）罗伯塔 · 迪 · 卡美丽诺

Accession Number：2014.1.937

罗伯塔 · 迪 · 卡美丽诺，意大利设计师，二战期间避难于瑞士，并在此开始手袋设计。1945年，卡美丽诺返回故乡威尼斯，开创品牌，最初以条纹天鹅绒背包和皮雕手袋为主产品, 后扩展开围巾、雨伞、腰带、鞋子和手套等不同品类。20 世纪50 年代开始设计、生产面料以及服装，活跃于美国时尚圈，并获得内曼. 马库斯时尚大奖。

## 艺术评鉴

此件套装出自罗伯塔·迪·卡美丽诺之手，承载着二十世纪六十年代意大利设计的独特风骨。设计师于战火流离中淬炼技艺，将威尼斯的波光与瑞士的沉静熔铸一炉，终成此作。条纹天鹅绒的肌理，令人遥想其早年手袋的经典语汇——那纵向流淌的色带，既似圣马可广场立柱的秩序，又如运河水面拉长的倒影，在织物表面形成富有韵律的视觉节拍。

六十年代正值其品牌由配饰向服装纵深拓展之际，此套装当是这一转型的见证。意大利战后设计的精髓，在于将手工艺的温度与工业时代的利落相调和；卡美丽诺更以面料设计先行，使纹样、色彩与剪裁互为表里，而非徒然附丽。其用色想必承袭了威尼斯画派的传统——宝石般的浓郁与光影的变幻，于庄重中透出戏剧性的华彩。

此作入藏中国丝绸博物馆，颇具深意。丝绸之路西传之技，经文艺复兴于意大利臻于化境，至二十世纪又以现代设计之姿回环东归。一衣一带之间，织绣文明的对话从未止息。卡美丽诺以难民之身起家，终获内曼·马库斯大奖，其个人史亦折射出战后欧洲时尚版图的重构。套装虽静默无言，却令观者触摸到一个时代的精神质地：创伤之后的重建，传统之上的革新，以及女性设计师于男性主导领域中开辟的独有天地。
