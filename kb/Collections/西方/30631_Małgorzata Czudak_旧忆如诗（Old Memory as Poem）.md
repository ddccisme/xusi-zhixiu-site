# Małgorzata Czudak：旧忆如诗（Old Memory as Poem）

## 描述

整体外形来源于传统的旗袍裙，特点是长裙和竖领斜襟，并以中国传统面料制成。设计师决意脱离传统形制，用波兰文化特色来诠释旗袍。下半身裙由手工精心编织，图案如同阿格涅斯卡的《我的祖母》里提到的童年时小地毯。上半身同样采用传统手工编织，设计师童年从母亲那里学会了技法。母亲曾制作了毛衣、帽子和围巾等物品，设计师虽已不记得卖出的价格，但自制的毛衣已珍惜地收藏了在家庭档案中。求学时期，设计师凭借学会的技法，制作了配件、帽子和手套等售卖，赚取了生活费。

设计师用了红色的线条在上身绲边，代表着旗袍的特色。立领不只是旗袍独有，在波兰文化中也极为风靡，因此设计师做了一定的装饰和修改。

## 艺术评鉴

此件"旧忆如诗"以旗袍之形为舟，渡波兰记忆之河，恰是丝绸之路精神在当代的私人性回响。设计师Czudak的巧思在于：非以东方符号猎奇，而是将两种身体的记忆编织为同一经纬。裙裾之纹样援引童年地毯，那是东欧平原上祖母的体温；上身绲边之红，既是旗袍的骨血，亦暗合斯拉夫民族对生命之色的虔敬。手工编织在此成为双重时间的载体——母亲传授的针法，求学时换取面包的技艺，皆凝固于纤维的交错之间。

最耐人寻味处，乃立领之变。旗袍竖领本是东方含蓄美学的脖颈，而波兰传统服饰亦重领饰之仪。Czudak不取其一端，而是让两种领语相互颉颃、彼此软化，终呈一种"之间"的姿态。红色绲边如一道细微的伤口，亦是缝合的针脚，标记着文化转译的临界点。

此作材质虽标"未知"，然其真正质地实为记忆本身——那些无法标价的毛衣、存入家庭档案的手泽、模糊售价却清晰触感的岁月。博物馆将其纳入中国丝绸之藏，恰是对"丝绸"概念的当代拓延：丝绸不再是单向输出的文明符号，而是全球织女共通的语言，是离散与归属的永恒辩证。旧忆之所以如诗，正因它拒绝确凿的叙事，只在经纬的缝隙间，让两种乡愁彼此辨认。
